# Changelog

## 0.1.0 — 2026-10-16

- New MCP server `office-mcp` (Python FastMCP, `mcp==1.30.0`) with eight tools: `create_docx`, `read_docx`,
  `edit_docx`, `create_xlsx`, `read_xlsx`, `update_xlsx`, `create_pptx`, `read_pptx`.
- Files in and out are Attachment-service ids through the proposed internal API; edits always create a new
  attachment. Owner comes from the proposed gateway-injected `owner_context_json`.
- Input checks: format and content type, macros, DTDs, zip-bomb limits, size limits; formula-injection protection
  for spreadsheets; read results marked `content_trust: "untrusted"`.
- Schema mismatches return JSON-RPC `-32602`; handler failures use the documented error envelope and codes.
- Deep Agent guides in `registry_docs/`, generated by `scripts/generate_registry_docs.py` and checked by tests that
  execute every documented case.
- Platform changes still needed: see `docs/technical/PLATFORM_DEPENDENCIES.md`.
